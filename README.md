# Frontend Mini-Projects & Web Practice Suite

A collection of interactive web applications, tools, and JavaScript practice algorithms built with HTML, CSS, and Vanilla JavaScript.

## 🚀 Projects Overview

| Project | Description | Main File |
| :--- | :--- | :--- |
| **Calculator** | String-based calculator tool parsing operators (`+`, `-`, `*`, `/`) | [`calculator/calculator.html`](./calculator/calculator.html) |
| **City Info Guide** | Demographic & status explorer for Indian cities | [`city-info-guide/cityStats.html`](./city-info-guide/cityStats.html) |
| **Color Flipper** | Random Hex color code generator with dynamic UI styling | [`color-flipper/color.html`](./color-flipper/color.html) |
| **Job Eligibility Checker** | Education qualification verification tool | [`job-checker/job.html`](./job-checker/job.html) |
| **Word Counter** | Real-time sentence word count analyzer | [`word-counter/words.html`](./word-counter/words.html) |
| **FD Rate Calculator** | Fixed Deposit interest rate calculator | [`fd-rate-calculator.html`](./fd-rate-calculator.html) |
| **Palindrome Checker** | String palindrome algorithm validator | [`palindrome-checker.html`](./palindrome-checker.html) |
| **Celsius to Fahrenheit** | Temperature conversion tool | [`celsius-to-fahrenheit.html`](./celsius-to-fahrenheit.html) |
| **JS Array Practice** | Dynamic `<select>` rendering & array utility functions | [`js-array-practice.html`](./js-array-practice.html) |
| **JS DOM Practice** | DOM selection, array manipulation & redirection | [`js-dom-practice.html`](./js-dom-practice.html) |
| **Landing Page** | Responsive layout featuring header, cards, & contact sections | [`index.html`](./index.html) |

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6+)**
